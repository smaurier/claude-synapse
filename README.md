# Synapse

**Don't sync memory across machines — link it.**

Under construction. Design phase complete (7 architecture decisions), extraction in progress.

This will be a Claude Code plugin that gives your memory a single physical home (a git repo
you own) and lets every machine and every project reference it by junction/symlink — never
a copy. No merge conflicts by construction, because there is never more than one exemplar.

Real README (thesis, comparison with existing sync-based tools, install instructions) lands
once the core mechanism is built and tested.
